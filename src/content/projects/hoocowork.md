Coding agents live in terminals, which is exactly where you are not when an idea
arrives. HooCowork puts one web interface in front of several of them — HooCode,
Claude Code, GitHub Copilot — running on your own machine or on a box somewhere
else, reachable from a phone.

The interesting part is not the chat window. It is the session model: projects,
provider configuration, MCP servers and running agents all have to stay coherent
across a connection that can drop at any moment.
